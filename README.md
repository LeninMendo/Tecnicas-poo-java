### Caso integrador: Sistema de gestión de estudiantes
Una institución educativa necesita desarrollar un sistema que permita registrar estudiantes y administrar sus calificaciones.

- Registrar estudiantes.
- Listar estudiantes.
- Buscar un estudiante por código.
- Registrar una calificación.
- Calcular el promedio.
- Evitar códigos de estudiante duplicados.
- Informar cuando un estudiante no existe.
- Controlar errores de ingreso de datos.
